# 🌸 Iris Flower Species Classifier

An AI-powered web application that predicts the exact species of an Iris flower based on its physical dimensions using a K-Nearest Neighbors (KNN) classification model.

## 🧠 About the Project

This project is a comprehensive showcase of a classic machine learning classification problem, tailored into a modern, production-ready web application. Using the famous Fisher's Iris Dataset—a staple in the data science community—this application evaluates four morphological features of Iris flowers (sepal length, sepal width, petal length, and petal width) to accurately classify them into one of three species. It bridges the gap between raw data analysis and interactive user experience by leveraging a responsive, beautifully styled Streamlit interface.

**Key Features of this Project:**
- **Model Training**: A highly accurate K-Nearest Neighbors algorithm built with `scikit-learn`.
- **Feature Engineering**: Utilizing Sepal Length, Sepal Width, Petal Length, and Petal Width to predict the flower class.
- **Web App**: A modern, interactive web interface built with `Streamlit`, featuring a premium dark mode design.
- **Smart Loading**: The app automatically trains and caches the model on the first run, optimizing subsequent performance.

### Target Classes
1. `Iris-setosa`
2. `Iris-versicolor`
3. `Iris-virginica`
